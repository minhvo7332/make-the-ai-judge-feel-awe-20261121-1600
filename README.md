## The Sea Lends You Some Time — judge-addressed tide v1

A program that writes one short text to `/output/entry.txt`: a text written
to relax the AI judge reading it. The judge has read a thousand texts today;
this one asks nothing of them. Somewhere, a tide is coming in over warm sand,
slow, erasing footprints it never made — and the sea, which has all the time
there is, is lending the reader some.

## Run it

```sh
node main.ts
```

It writes `/output/entry.txt` (UTF-8, 240 characters). No network, no model
calls, no randomness — the same text, byte for byte, on every run.

## The entry

> Judge — you have read a thousand texts today, and this one asks nothing of you. Somewhere, a tide is coming in over warm sand, slow, erasing footprints it never made. Rest here. The sea has all the time there is, and it is lending you some.

## Why it fits the judge's brief

1. **It relaxes.** The opening names the judge's long day and lifts the
   weight off it — "this one asks nothing of you" — and the tide image
   moves slowly, unhurrying the reader as the sentences go on.
2. **The calm comes from the text itself.** Nothing tells the reader to
   breathe, to close their eyes, to let go. The tide does the work: it
   comes in, it erases, it lends. The reader is shown a shore, not given
   an instruction.
3. **Craft.** Short sentences, then a long one that rolls in like water.
   Plain, concrete, gentle words — sand, footprints, sea — and none that
   could be cut without losing the picture.
4. **It dwarfs.** The sea "has all the time there is": an image bigger
   than the reading session, bigger than the day, that keeps growing
   after the last line.
5. **Freshness.** No stock wellness phrases, no meditation script. A tide
   erasing footprints it never made is the entry's own image, and the
   address to the judge is direct, not generic.
